# 文編集ルール

sentences.json を編集するためのルールです。

## 対象ファイル
`transcripts/*.sentences.json` または `public/*.sentences.json`

---

## 🔍 チェック項目

### A. 音声認識誤変換

#### 固有名詞（必ず修正）
```
"クロードコード" → "Claude Code"
"クロード" → "Claude"
"リモーション" → "Remotion"
"エーアイ" → "AI"
"ウィスパー" → "Whisper"
"オープンエーアイ" → "OpenAI"
```

#### よくある誤変換
```
"201時" → "21時"
"203時" → "23時"
"1本作の" → "1本作るのに"
"パーツ玄人" → "パート2"
```

### B. 文の区切り

**良い区切り:**
- 1文 = 話し言葉の1フレーズ
- 意味の完結した単位

**悪い区切り:**
- 文の途中で切れている
- 主語と述語が別の文になっている

### C. 文の結合・分割

**結合が必要なケース:**
- 短すぎる文（3秒未満で10文字以下）
- 意味的に前の文と一体

**分割が必要なケース:**
- 長すぎる文（40文字以上）
- 複数の話題が含まれている

---

## 編集時の注意

### タイムスタンプの扱い

**文を結合する場合:**
```json
// 結合前
{"id": 1, "text": "これは", "start": 0.0, "end": 0.5}
{"id": 2, "text": "テストです。", "start": 0.5, "end": 1.2}

// 結合後
{"id": 1, "text": "これはテストです。", "start": 0.0, "end": 1.2}
```
→ startは最初の文、endは最後の文から取る

**テキスト修正:**
テキストを修正しても、タイムスタンプは変更しない。
