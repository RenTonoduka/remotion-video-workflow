# サムネイル挿入コマンド

`thumbnail-inserter` エージェントを起動して、テロップに合わせたサムネイル挿入を行います。

## 使い方

```bash
# 基本
/add-thumbnail

# 引数付き
/add-thumbnail "AIで業務効率化する方法" のテロップに AIで業務効率化する方法.png を挿入
```

## 実行

```
Task tool:
- subagent_type: "thumbnail-inserter"
- prompt: "$ARGUMENTS を使ってサムネイル挿入を実行してください"
```

## 対話例

### 1枚挿入

```
ユーザー: /add-thumbnail
エージェント: どのテロップに合わせてサムネイルを表示しますか？
ユーザー: 「今日の内容をもっと深掘り」のテロップに「AI×動画編集WS体験会.png」を表示して
エージェント:
- subtitleData.ts を検索...
- startFrame: 4022, endFrame: 4200 を取得
- insertImageData.ts に追加完了
- seData.ts にスライドインSE追加完了
```

### 複数枚挿入

```
ユーザー: /add-thumbnail 3枚を0.5秒ずらして表示
エージェント: どのテロップに合わせますか？また、画像ファイル名を教えてください。
ユーザー:
- テロップ: 「こういった動画を見逃したくない方は」
- 画像: AIでアプリ開発する方法.png, AIで業務効率化する方法.png, AIで自動化する方法.png
エージェント:
- 3枚をposition 0, 1, 2で配置
- 0.5秒（13フレーム）ずらしてスライドイン
- 完了！
```

### 動画サムネイル

```
ユーザー: /add-thumbnail 動画を挿入したい
エージェント: 動画ファイル名と表示タイミングのテロップを教えてください。
ユーザー: 「過去のライブ配信動画を」のテロップに GPTs研究会ライブ配信アーカイブ.mov を表示
エージェント:
- type: video-thumbnail で追加
- seData.ts にカーソル移動1 (2).mp3 追加
- 完了！
```

### グリーンバック動画

```
ユーザー: /add-thumbnail LINE登録.mp4 をグリーンバックで挿入
エージェント: どのテロップに合わせますか？
ユーザー: 「概要欄のURLからライン登録して」
エージェント:
- type: video-greenscreen で追加
- 右側からスライドイン設定
- seData.ts にSE追加
- 完了！
```

## 必要な入力

1. **テロップキーワード**: どのテロップに合わせるか
2. **画像/動画ファイル**: 挿入するファイル名
3. **タイプ**: thumbnail / video-thumbnail / video-greenscreen（自動判定可）
4. **終了タイミング**: いつまで表示するか（省略可）

## 自動処理

- ファイル拡張子から type を自動判定
- 最後のID + 1 で連番付与
- SE は type に応じて自動選択
- position は 0, 1, 2 を順番に割り当て
