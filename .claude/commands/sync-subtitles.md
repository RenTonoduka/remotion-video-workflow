# 音声同期チェック

`sync-adjuster` エージェントを起動して、音声とテロップのタイミング同期を診断・修正します。

## 入力
- SRTファイルパス（オプション）: $ARGUMENTS

## 実行

```
Task tool:
- subagent_type: "sync-adjuster"
- prompt: "音声同期を診断してください。SRTファイル: $ARGUMENTS"
```

## エージェントが行うこと

1. **SRTファイル読み込み** - 正解データとして使用
2. **subtitleData.ts読み込み** - 現在のテロップデータ
3. **タイミング比較** - SRTとsubtitleDataのフレーム比較
4. **ずれ検出** - 許容範囲外のずれを報告
5. **ユーザー確認** - 修正方法を確認
6. **慎重に修正** - 確認を得てから修正

## ずれの判定基準

| ずれ | 判定 | 対応 |
|------|------|------|
| 0〜3フレーム | ✅ 許容 | 無視 |
| 4〜15フレーム | ⚠️ 軽微 | 報告、確認後修正 |
| 16フレーム以上 | ❌ 要修正 | 報告、慎重に修正 |

## ⚠️ 重要な注意事項

- **SRTファイルが正解**（音声認識から生成されたタイムスタンプ）
- **勝手にタイミングを変えない**
- **修正前に必ずユーザーに確認**
- **一括修正より個別確認を優先**

## 使用するスキル
- `sync-rules` - 音声同期のルールと診断基準
