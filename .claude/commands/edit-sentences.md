# 文編集

`sentence-editor` エージェントを起動して、文単位の編集を行います。

## 実行

```
Task tool:
- subagent_type: "sentence-editor"
- prompt: "public/audio.sentences.json を読み込んで診断し、問題があれば報告してください"
```

## エージェントが行うこと

1. **自動診断**
   - 音声認識誤変換（クロードコード等）
   - 固有名詞の表記
   - 文の区切り
   - 短すぎる/長すぎる文

2. **診断結果報告**

3. **ユーザー指示に従って修正**

## 自動修正OK

- 音声認識誤変換
- 固有名詞の表記

## 確認が必要

- 文の結合
- 文の分割
- 文の削除

## 使用するスキル

- `sentence-rules` - 文編集のルールと基準
